# zenbot 美术母版规范

## 唯一母版

- 原始母体：`Q版形象迁移创作.png`，清洁副本保存在下列 source 目录。
- 清洁透明母版：`assets/characters/zenbot/source/zenbot-master.png`
- 生成参照图：`assets/characters/zenbot/source/zenbot-master-trim.png`
- 角色 ID：`zenbot`
- 不得覆盖或修改用户下载的原始母体。

## 必须保持

- 母体原样的 Q 版大头、小短身、短腿比例。
- 浅银蓝到青蓝再到淡紫的长发渐变、同款发束走向与发梢。
- 青色大眼、同款眼型、眼高、虹膜比例和柔和腮红。
- 星星蝴蝶结、月亮发饰、绕颈耳机、黑白科技外套、深色百褶裙、深色裤袜、蓝白运动短靴。
- 胸牌文字 `Zenix+`，不增加其他文字或标志。
- 干净深蓝轮廓、平涂色块加少量柔和渐变、正面或轻微三分之四站姿。
- 角色脚底在统一基线落地，人物完整可见且居中稳定。

## 禁止

- 鲸鱼鳍、鲸鱼尾巴、女仆装、围裙、鲸鱼标志或任何鲸鱼娘外形残留。
- 重新设计脸型、眼型、发型、服装或配色。
- 漂浮、半透明、发光轮廓、厚涂、写实、3D、像素风、背景场景。
- 多余角色、道具堆叠、画面文字、署名、生成平台水印。

## 输出

- 每个词条一张独立透明 PNG，不输出整张拼图代替单帧。
- 表情：保持母体站姿，只改变眉眼、嘴形、腮红、汗滴、眼泪、爱心、怒气符号等表情元素。
- 动作：保持同一人物，改变身体姿态，给出该动作最易识别的静态关键帧。
- 文件命名使用词条 ID：
  - 19 个表情：`assets/characters/zenbot/expressions/<id>.png`
  - 18 个动作：`assets/characters/zenbot/motions/<id>.png`

## 表情词条

- `neutral`：平静，母体默认表情。
- `happy`：双眼弯成开心弧线，张嘴笑，轻微腮红。
- `wink`：一只眼眨眼，另一只眼睁开，微笑。
- `love`：心形眼，周围漂浮小心心，害羞。
- `shy`：脸红，视线躲开。
- `surprised`：双眼睁大，惊讶张嘴，头顶感叹号。
- `angry`：皱眉，头顶怒气符号，鼓脸。
- `sad`：八字眉，低头，眼泪和悲伤垂肩。
- `sleepy`：半眯眼打哈欠，头顶困倦符号。
- `thinking`：视线向上，手托下巴，头顶思考圈。
- `smug`：半眯眼侧看，得意微笑。
- `pout`：嘟嘴、鼓脸、脸红，微微扭头。
- `worried`：八字眉，紧张，冒冷汗。
- `determined`：眉眼压低，认真坚定。
- `flustered`：`>` `<` 眼，满脸通红冒汗，手忙脚乱。
- `scared`：瞳孔缩小，后退半步，冒汗发抖。
- `excited`：星星眼，张嘴笑，期待地握拳。
- `cry`：闭眼大哭，眼泪直流。
- `confused`：歪头不解，头顶问号。

## 动作词条

- `stand`：自然站稳，可轻微舒展。
- `jump`：双脚离地，双臂上举的跳跃最高点。
- `hop`：小幅离地、膝盖微弯的轻跳。
- `look`：一手作遮光状，身体侧倾张望。
- `turn`：身体转到三分之二侧面的转身关键帧。
- `nod`：低头、闭眼认同。
- `shake`：头部左右摆动的拒绝关键帧，配合摇头线。
- `spin`：原地旋转，裙摆和长发展开。
- `sit`：双腿并拢坐在地上，双手放在膝盖附近。
- `sleep`：坐着打盹，头歪向一侧，`Z` 符号。
- `dizzy`：脚步不稳，圈圈眼，头顶旋涡。
- `walk`：自然步行的中段姿势。
- `run`：冲刺中段，身体前倾、长发后扬。
- `wave`：一只手举起挥动，开心微笑。
- `bow`：闭眼、上身向前鞠躬。
- `shiver`：缩肩抱住手臂，发抖线和冷汗。
- `flap`：开心蹦起，双臂像小翅膀一样扑腾，长发与外套下摆扬起。
- `dance`：踩着节拍摇摆，一臂举起，周围漂浮音符。

## 生成参照

每次生成都必须引用 `zenbot-master-trim.png`。所有表情和动作使用同一套基础描述，只逐条替换表情或动作。
