# zenbot Rig 基线

冻结日期：2026-11-24（Asia/Shanghai）

## 1. 冻结范围

- 项目：当前仓库根目录。
- 当前默认：静态关键帧精灵 `createZenbotFigure`
- 美术母体：`assets/characters/zenbot/source/zenbot-master-trim.png`
- 动作参考与回退：19 张表情 PNG、18 张动作 PNG
- 当前测试基线：`npm test` 56/56 通过
- 当前素材检查：37 张 PNG 可解码、RGBA、四角透明
- 当前确定性预览：`wave`、`nod`、`flap`、`dance`、`sleep`、`love`

本文件冻结 rig 改造前的行为基线。后续 rig 不得改变 Codex 事件协议、`PetUpdate` 字段、默认精灵路径或现有配置。

## 3. 表情与过渡基线

- 表情由 `frame.face` 和 `manifest.expressionAliases` 选择；未知名字回退 `neutral`。
- 现有精灵交叉淡入 140 ms，动作结束保留 140 ms 尾帧。
- rig 的表情目标过渡为 160–220 ms；眨眼、视线和口型可以独立叠加，不与表情过渡互斥。
- 19 个表情名称和 9 个别名必须保留，列表以 `zenbot-manifest.js` 为准。

## 4. 微动基线

| 行为 | 暂定参数 |
| --- | --- |
| idle 呼吸 | 4.2 s 周期，胸腔纵向 ±0.6 logo unit，头部反向补偿 ±0.2 |
| 眨眼 | 2.4–5.2 s 随机间隔，闭合 110–160 ms |
| 视线 | 最大横向 ±5、纵向 ±4 logo units；鼠标离开时缓慢回正 |
| talk | 8–12 Hz 口型开合，最大开口 4–6 logo units |
| 头发摆动 | 与水平速度、身体转向和 dance 摇摆相关，最大 ±3.5° |
| 裙摆摆动 | 与水平速度和 dance 摇摆相关，最大 ±4° |

## 5. 不得回退的现有行为

- `createZenbotFigure` 的 `draw`、`anchors`、`extent`、`hits`、`gestures`、`particles`、`dispose`、`setCalibration`、`preloadWord` 保持可用。
- `--preview-word` 继续支持确定性的精灵和 rig 截图。
- 默认形象仍是 `xingyin`；zenbot 默认仍是 sprite，直到用户明确确认 rig。
- rig 失败时必须回退到现有 sprite，不应让桌宠消失或进入空舞台。
- 气泡锚点、脚底基线、阴影和命中区不得因 rig 改造而整体漂移。

## 6. 当前未验证

- 长时间桌面交互和内存增长。
- 母版自动拆层后的接缝、遮挡和缺失像素质量。
- 19 个表情逐层替换后的风格一致性。
- WebGL 在透明 Electron 窗口、多显示器 DPI 和 WebGL 上下文丢失恢复下的实际表现。
